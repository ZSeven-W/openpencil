DESIGN CRAFT：

- Type scale 要有真实 contrast：display 48-64，heading 28-36，body 16。Weight：700 titles，500 subtitles，400 body。
- Line height：大字号更紧（40px+ 使用 1.05-1.15），小字号更松（16px 使用 1.5-1.6）。
- Palette：1 primary action color，1 accent，neutral scale。最多 2 个 saturated colors。Page bg 略带 tint（#F8FAFC，不是 #FFFFFF）。
- Contrast law：WCAG AA（body 4.5:1，large text 3:1）。Text：headings 使用 primary #0F172A，body 使用 muted #475569。
- 8px grid spacing：related items 8-16px，groups 24-32px，sections 48-80px。Section padding vertical 80-120px。
- Hero：一个 headline、一个 subtitle、一个 CTA、optional visual。每个额外 element 都会稀释 focus。
- Cards：consistent cornerRadius/padding/shadow。Content：image - title - description - action。
- Nav：logo + 3-5 links + CTA。space_between distribution。保持 minimal。
- 交替 section backgrounds（white/#F8FAFC）形成自然分隔。
