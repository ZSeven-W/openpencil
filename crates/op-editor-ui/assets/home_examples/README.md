# Home example art assets

`coffee-demo.jpg` — 360×540 demo photograph. It is generated concept material
carried over from the design prototype
(`openpencil-docs/prototypes/entry-home-studio/assets/coffee.png`, resized and
re-encoded here); it is NOT an OpenPencil generation result and must never be
presented as one. Two consumers: the Studio home's screenshot-tutorial explore
card (its small corner phone), and the `coffee-order-app` scene template, whose
generator (`templates/step0/_generators/tpl_app_coffee_order.py`) inlines it as
the featured-drink image slot. Keep the folder under 250 KB (desktop bundle
size gate).
