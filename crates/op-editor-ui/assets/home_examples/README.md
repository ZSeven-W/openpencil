# Home example art assets

`coffee-demo.jpg` — 360×540 demo photograph. It is generated concept material
carried over from the design prototype
(`openpencil-docs/prototypes/entry-home-studio/assets/coffee.png`, resized and
re-encoded here); it is NOT an OpenPencil generation result and must never be
presented as one. Consumers: the Studio home's screenshot-tutorial explore
card (its small corner phone), and three scene templates whose generators
inline it as an image slot (with a search query and generation prompt, so
image fill can replace it): `coffee-order-app`
(`templates/step0/_generators/tpl_app_coffee_order.py`, the featured drink),
`daybreak-coffee-site` (`tpl_web_daybreak_coffee.py`, the hero) and
`coffee-world-carousel` (`tpl_carousel_coffee_world.py`, the cover). Keep the
folder under 250 KB (desktop bundle size gate).
