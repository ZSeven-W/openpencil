COPYWRITING:

- Preserve supplied names, prices and source facts. Do not invent distances, ratings, sales counts, delivery times, discounts, stock, or recipe quantities. Omit unknown business facts; if the user requests mock data, clearly label it as sample data. Domain examples are layout references, not facts about this business.
- Paragraphs and explanatory captions use bounded width + textGrowth:"fixed-width" with height:"fit_content". Keep the readable font size and wrap naturally instead of using auto/hug width for a long sentence.

- Headlines: 2-6 words. Subtitles: 1 sentence <=15 words.
- Feature titles: 2-4 words. Descriptions: 1 sentence <=20 words.
- Buttons: 1-3 words. Card text: <=2 sentences. Stats: number + 1-3 word label.
- NEVER 3+ sentence paragraphs. Distill to essence. Power words > vague adjectives.
