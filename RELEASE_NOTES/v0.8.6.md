# OpenPencil v0.8.6 — Motion Authoring and Export

This release adds motion authoring on the canvas, shared playback with Jian,
interactive HTML export, and browser-local MP4 export.

## Motion authoring and playback

- Edit keyframes, easing and stagger in the Motion inspector and timeline.
  Scrub the playhead to see the sampled frame directly on the canvas.
- Trigger named clips from interactions and author screen transitions.
  Replay motion in Play while keeping the current screen and input values.
- Jian desktop and Web players use the shared motion runtime. Wheel and
  trackpad scrolling move the rendered content, hit targets and in-view
  animation checks together.
- Standalone HTML evaluates dynamic routes and runs local event chains with
  state changes, conditions, delays, parallel branches, visibility changes
  and named clips.

## Export and automation

Export clips as GIF, APNG, a ZIP of PNG frames, or H.264 MP4. The desktop and
daemon use the same in-process Rust frame clock, H.264 encoder and MP4 muxer
as the browser WebAssembly build. The browser paints into a local CanvasKit
raster surface and can download the MP4 offline once the document and its
assets are loaded. MP4 encoding and muxing require no external encoder.

The CLI and MCP expose motion export, and MCP can return sampled frames
for an agent to inspect its own animations.
